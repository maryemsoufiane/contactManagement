# Contact Management API

## 🎯 Why this project?

I created this project for a simple reason: **to code by myself again.**

With the growing use of AI tools, it is easy to get used to asking for solutions instead of thinking, searching, making mistakes, debugging, and building things step by step.

So I decided to take a step back from AI and rebuild this project **by myself**, even if the starting point is just a simple Contact Management API.

This repository is my way to:

* 🧠 Review concepts that I may have forgotten or become less comfortable with because of AI.
* 💻 Practice coding without relying on AI to write the solution for me.
* 🔎 Understand what happens behind the code instead of just copying a solution.
* 🐛 Make mistakes, debug them, and learn from them.
* 🚀 Progress step by step from a simple CRUD API to a more advanced application.
* ❤️ Rediscover the feeling and satisfaction of writing code myself.

## 🚧 Project Status

This project is intentionally being developed **step by step**.

I don't want to rush to the final architecture.

Each new feature should be an opportunity to understand a concept, write the code myself, make mistakes, debug them, and improve the implementation.

**Simple first. Advanced later.**

## 🤖 My Rule About AI

For this project, AI is not going to write the code for me.

I can use documentation, search, debugging tools, and official resources when I am stuck, but I want to make the important decisions and write the implementation myself.

The objective is not to prove that I can code without ever using AI.

The objective is to make sure that **I still know how to code without depending on it.**
